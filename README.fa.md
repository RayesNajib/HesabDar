درباره حساب‌دار

حساب‌دار یک اپلیکیشن مدیریت مالی شخصی است که برای ثبت و مدیریت درآمدها، هزینه‌ها، طلب‌ها و فعالیت‌های مالی روزانه طراحی شده است.

فرقی نمی‌کند حقوق ماهانه دریافت کنید، روزمزد باشید یا درآمد نامنظم داشته باشید؛ حساب‌دار کمک می‌کند وضعیت مالی خود را دقیق‌تر بشناسید.

حریم خصوصی

حساب‌دار با رویکرد آفلاین‌محور طراحی شده است. اطلاعات مالی کاربران به‌صورت محلی روی دستگاه ذخیره می‌شوند.

مجوز استفاده

حساب‌دار یک نرم‌افزار اختصاصی است.

دانلود و استفاده شخصی از برنامه مطابق شرایط مجوز آن مجاز است. کپی‌برداری، تغییر، فروش و انتشار مجدد بدون اجازه سازنده ممنوع است.
